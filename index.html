    5대 영역 활용법, SRS 4단계 복습 주기, 전역 단축키를 안내합니다.

    📌 5대 영역 학습 가이드
    • 대시보드: 어휘·문법·독해 진도율과 오늘 복습 합계, 취약 현황 및 JSON 백업/복원을 관리합니다.
    • 문자·어휘: 어휘 대시보드에서 시작해 단어장(50개 단위 지연 렌더링), 플래시카드, 퀴즈, 오답노트를 이어갑니다.
    • 문법: 문법 대시보드, 접속 형태·상태 필터, 유사 문법 비교, 문법 플래시카드와 문법 퀴즈를 제공합니다.
    • 독해: 지문 유형별 본문과 문맥 완성 문제, 어휘·문법 연계 해설을 학습합니다.
    🧠 SRS 4단계 복습 주기 안내

    플래시카드 및 퀴즈 평가에 따라 다음 복습 예정일이 자동 계산되어 오늘 복습 목록에 올라옵니다.

    • 미학습: 아직 학습하지 않은 초기 상태입니다.
    • 모름 (1일): 다음 날 바로 재복습하도록 설정합니다.
    • 애매함 (2일): 2일 뒤 재확인하여 장기 기억으로 전환합니다.
    • 완벽함 (SRS): 복습 간격이 점진적으로 늘어나며(3일 → 7일 → 점진 확장) 효율적으로 복습합니다.

    ⌨️ 단축키 안내

    입력창(`input`, `textarea`, `select`)에 포커스가 있을 때는 단축키가 일시 정지됩니다.

    • Space: 플래시카드 뒤집기
    • ← / →: 이전 / 다음 카드
    • R: TTS 발음 듣기
    • 0 / 1 / 2 / 3: 미학습 / 모름 / 애매함 / 완벽함 평가
    • K / M: 히라가나 가림 / 뜻 가림 토글
    • ?: 이 안내 창 열기/닫기
